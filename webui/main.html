Quick Start

  1. Ensure dependencies are installed (click "Check Status" above)
  2. Ask the agent: "Transcribe this YouTube video: https://youtube.com/watch?v=..."

  4. For detailed notes: "Create detailed notes from: https://youtube.com/watch?v=..."
  5. For playlists: "Transcribe this playlist: https://youtube.com/playlist?list=..."
